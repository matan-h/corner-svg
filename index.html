by matan-h

Zoom into random corners of the image and discover :).

H UI   I info   +/- zoom   0 reset

Mouse: wheel to pan, Ctrl+wheel to zoom, middle-drag to pan.
Touch: drag to pan, pinch to zoom.

This wrapper site is an (AI-generated) simple golfed SVG viewer, because Chrome limits you to 25% zoom. If you have a good image viewer, you can download the SVG art from here.

The site, and the SVG are open source, in a github repo.

Warning: this wrapper site does not work properly on Firefox!!.
